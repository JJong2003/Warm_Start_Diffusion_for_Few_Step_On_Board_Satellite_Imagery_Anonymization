운영자 설정 · 서버 연동 가이드
현재: 데모 모드 (서버 주소 미설정)

여기서 입력한 주소는 새로고침하면 사라집니다. 실제 배포 시에는 /js/main.js의 DEFAULT_API_BASE_URL 값에 서버 주소를 직접 넣어두면, 방문자는 아무 설정 없이 바로 실제 모델 결과를 받게 됩니다.

서버는 큐잉을 감안해 동기 응답 대신 작업 제출 + 폴링 방식을 사용합니다. 프런트엔드와 다른 도메인에 서버를 두면 CORS 허용 헤더가 필요합니다.

1) 작업 제출
POST {서버주소}/api/jobs   (multipart/form-data: image, model_id)
→ { "job_id": "...", "queue_position": 3 }

2) 상태 폴링
GET {서버주소}/api/jobs/{job_id}
→ {
    "status": "queued" | "processing" | "done" | "error",
    "queue_position": 2,          // status가 queued일 때만
    "result": {                   // status가 done일 때만
      "boxes_image":  "data:image/png;base64,...",
      "mask_image":   "data:image/png;base64,...",
      "coarse_fill_image": "data:image/png;base64,...",
      "diffusion_preview_image": "data:image/png;base64,...",
      "result_image": "data:image/png;base64,...",
      "meta": { "detections": 1, "nfe": 10, "latency_ms": 298, "mock": true }
    },
    "error_message": "..."         // status가 error일 때만
  }
